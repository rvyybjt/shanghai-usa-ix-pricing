## 沪美 IX 是什么：和普通沪美 IPLC 差在哪

Mkcloud 的沪美 IX，官方全称是“沪美专线上云互联优化专线（IXP）”。按官方知识库的描述，它交付的还是一台出海 VPS：每台机器分配 1 个独立入口 IP 和 1 个独立出口 IP，你连入口操作，程序自动从美国 BGP 出口向外访问。它不是能把你办公室和美国云 VPC 直连起来的“裸专线”。

和普通沪美 IPLC 的核心区别在入口。直连款（上海电信入口）绑定一个连入省份，换省份要自己在后台改；IX 版不限连入省份，但只允许云厂 BGP 网络连入——上海入口目前支持阿里云、腾讯云、百度云国内全网，以及火山云、华为云、UCloud 华东，具体以购物车页面为准。也就是说，你得先有一台符合条件的云主机当前置，从它连到 IX VPS 的入口。

延迟方面，官方产品资料给的端内参考是 **124~134ms**。官方反复强调这是端内参考值，不包含你本地到入口、以及美国出口到目标平台的耗时，别把它当成“你 ping 亚马逊的延迟”。

为什么 IX 便宜？第三方测评（虎窝博客对同系列沪港 IXP 的实测）解释过机制：这类入口 IP 只在交换中心内对云厂大厂宣告，三大运营商的公网根本访问不到，入口侧的带宽和保护成本天然更低，售价也就压下来了。

## 下单前要确认的几件事

沪美 IX 的便宜有明确的前提条件，这些都在购物车页面和官方知识库里写明了：

1. **实名与用途**：需中国身份信息实名，仅限正规用途，明令禁止机场、回国等违法违规用法，一经发现清退且不退款。
2. **前置条件**：只允许云厂 BGP 网络连入（阿里云、腾讯云、百度云国内全网，火山云、华为云、UCloud 华东等），普通家宽或一般 BGP 主机不能当前置。
3. **流量规则**：计量型套餐按上下行双向统计，超量停机；可自助购买流量重置或工单补差价升级。
4. **退款与地域**：仅质量问题支持退款，且要提交具体延迟、速度数据作为证据；开通后不支持更换到其他地域的产品。
5. **出口能力**：出口 IP 不支持外部连入，不能承载公开网站、支付回调、邮件接收或游戏服务端；IP 不保证原生或历史干净。
6. **SLA**：标准产品默认无 SLA 保证，对连续性要求高的业务先走工单确认付费定制。

还有一点容易被忽略：升降级都要提交工单，降级到更低套餐时差价不退。开通倒是快，官方口径是现货约 1 分钟自动开通。

## 常见问题

**沪美 IX 需要自己的 ASN 或 IX 端口吗？**

不需要。零售 VPS 用户买的是商家交付好的产品，交换中心成员接入是另一类服务。官方 FAQ 明确写了“零售 VPS 用户不需要”。

**超流量之后会断网吗？**

会。IXP 流量计费套餐超量直接停机，可以在后台购买流量重置，或者提交工单补差价升级套餐。这也是为什么选档时建议留出余量——双向统计意味着实际消耗比很多人以为的快。

**出口 IP 能不能拿来挂网站、收支付回调？**

不能。出口方向只出不进，官方在产品页和知识库里都排除了公开网站、支付回调、游戏服务端这类需要接收入站的用途。美区店铺后台、API 调用、文件传输这些主动向外的场景才是它的主场。

**和上海 BGP 入口的独享款比怎么选？**

官网沪美方向还有上海 BGP 入口的独享产品，BGP 入口对单运营商宽带的兼容性更好一些。价格以购物车实时展示为准，两款可以放在一起比。

**买错了能退吗？**

只有质量问题能退，而且要拿出具体的延迟、速度数据证明是产品服务问题；开通后不能换地域。下单前先确认方向、入口和套餐档位，比事后扯皮划算得多。
